趁着开了一夜空调残留的冷气，把八月上的日记开了。明明改成用 GitHub issue 发日记之后，理论上方便了很多，毕竟手机里有 GitHub App，电脑随便开个网页就能提交，但似乎没怎么更新。戒赌也没成功，到昨天依旧沉迷于德州。原以为给自己找个兼职，伟大的使命能拯救空虚的自己，到头来也只是再次证明了我是个烂泥罢了。

  • 睡了八小时还是困，总觉得睡不够。和人说从七牛辞职之后第一天，什么都不干，我一定要睡上一天；
  • 昨天输了 80k 筹码，又一次开始反思，自己在赌什么（牌面？还是赢 chips）刚在给番茄和葱白准备早饭的时候，想到一件事，自己的德州一直都是靠运气，没有任何技巧。而这种牌类，不是一个温和型比赛，只有输赢。那么，它就和我秉持的 better 原则是相悖的，想到这，又一次索然无味（大概每个赌狗输了钱之后总会找补。昨天输完 80k chips 的时候是傍晚，最后跑去做了宣传单页。发现，其实做东西，有产出带来的快乐，虽然没有赢大 chips 来得大，但似乎也不差。立个 flag，就让剩下的 521k 的 chips 留守吧，老子要戒赌！
  • 昨天给 mem 做了个宣传单页？它不是传统意义上的宣传单页，不知道 wey 和 weizhen 收不收货，如果收货的话，o.o 希望它能被人拍照流传出去；
  • 图片比视频好做，宣传单页做完了，宣传片其实周四就在准备了。一直没想到好的思路，昨天看到一个推说，张朝阳的金句拯救了他/她，如果你拖延，那就在脑子里开始推演如何一步步去实现这个点子。我拖延三天半，也没想出来这个宣传片到底怎么呈现好。说到底，和宣传单页一样，我脑子的想法是，做个不一样的宣传片出来。但…我的实力跟不上我的野心；
  • 说到野心，之前把市场部交出去了，我看人真的垃圾。40 比我想象的…要没想法点。对，很土的一个形容，没想法。我原以为她会做很多事情，事实上，内容侧，她没有任何上报的选题。我在反思，是否自己坦白和她说我没打算干长工，给了她不尽力干活的理由。现在想来，也许，自己才是异类。虽然我没打算干长工，但至少尽力把能做的事情都安排上，开始做了。但有些人是会收着。大概自己才是异类吧，可是我又有什么立场去说些什么呢？
  • 上周入了一盒皮爷的冻干咖啡，我还挺喜欢的，念念说不好喝，酸。即便有差评也不妨碍我把它分享给她人，所以给上海的同事，还有 wenting 下单了。这种，好评坏评参半的东西，我选择去安利给他人，也是因为。。。以自己为重吧；
