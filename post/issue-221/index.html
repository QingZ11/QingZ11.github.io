这年头，断网就跟断生产力没啥区别。展馆的网络太差了，估计是 2.4G 的频道不行了，而伟大的 pixel 10a 不支持 5G，这时候我才想起来，5G 是一个有用的存在。但这不妨碍 VS Code 的本地使用，即便 ChatGPT 和 X 都掉线了。

前几天，在 tg 群里，盐粒辟谣了一个关于他公司的创始人包养 COO 的“谣言”。类似的桃色新闻，nebula 也有。但我不传，也不辟谣，因为我不知道事实如何。所以，盐粒狠狠地在我这刷了一波好感。真不错！能辟谣，能坚定地否定他人说的“我只是听说”“你们内部人说”这种话术的人。我真心觉得，这小伙子真不错啊，真不错！！因为很多人不了解情况，看见人那么说，加上内部人员的噱头，很容易就相信了。对于无关痛痒的信息，大多数人是懒得去求证是否如此的。传出去，比验证它更符合社交的利益。

反之，我不喜欢以“你们内部人”“听说 xx 公司…”这种信息和人家交流的。我将信息分成两种，一种是无效信息，一种是带你认识、了解世界的信息。后者有美食信息、知识信息，无关于某个具体生活在周遭人的信息，例如某个梵高的成长史等等。前者，大多数家长里短，以及流传在职员、某个公司成员和外部人员之间的某公司内部信息。就像我之前说的那样，公司的名声，是一个很难维护的东西。所以，我不喜欢一切建立在前者信息共享基础上的关系，大多数这类人，我也慢慢的疏远了，比如月月（对不起，你是个好人）。

我不好八卦

事实上，我最近发现了一件事，以前者信息为社交媒介的人，会在某种程度上标榜自己并不是爱好八卦之人，甚至会和我抨击另外一个人打探消息，太八卦。我有些不得解，但是在地铁发呆的时候，我想明白了一件事，就是没有标准的时候，人会以自己为标准。

比如，我是个好人、我是个不爱好八卦的人。如果以对桃色信息、职场不对称信息的主动性作为标准，你比我主动去触及这种消息，那你就是比我八卦。所以，念念会和我说露露很八卦。事实上，她比我八卦，因为她说了不少 +1 的桃色信息给我。对于没法判断，无法确认事实与否的事情，我保持沉默，也不会给什么具体的反应。话说回来，除非有上帝视角，不然人们怎么能得知事实如何呢——所以，我的处理方式也存在着悖论。

回到标准这件事，地铁上我想到，只要没有标准，人自己的标准就是尺子。但换个角度，如果能统计到足够多的样本，那就会存在一个社会性质的平均值，那就可以说你比正常人更好，或者更没素质。说到这，我想起了，以他人为标准的话，相比 siwei，我其实不是个好人，但按照社会的平均值，我其实妥妥的是个好人。所以标准很重要。

但想了下，能有具体标准和数值的，也只有数理化了，可惜这些学科我很一般，谈不上烂，就是一般。到头来，我也只是一个普通仔，一般般罢了。

anyway，我觉得盐粒真是伟大！伟大！我钦佩一些和一些不利于美好化事物说不，纠正它的人。

兜底和劝诫

发现最近自己有一个偏好，可能比起早些年让人更健康地生活（改变人的行为模式），现在更倾向为行为结果兜底。

以熬夜为例，如果早些年，我可能会说熬夜不好吧啦啦的。现在我已经充分尊重个人的行为模式，熬夜就熬呗，喝酒就喝呗，劝诫没啥用–不是行为不对，而是人的情绪是很重要的。如果熬夜，喝酒，宅着，吃垃圾食品，能让人有片刻的愉悦，那就应该去做。及时行乐吗。至于它的后果，那就是我最近开始会努力关注的。

如何在既定行为模式下，适当减少它的不良后果。所以我往办公室寄了一堆健康食物。因为 siwei 真人熬夜我管不着，即使我觉得是他们的伴侣也不应该打着为他们好的名义，去左右他们的行为。所以，行为带来的后果就是食补，你吃点健康的东西，对冲下。所以，我买坚果，这种我觉得更好，我已经是个成熟的成年人了，要学会为行为带来的结果兜底。
